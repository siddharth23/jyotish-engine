# Accuracy and Verification

## Method

Every release is validated against `test/vectors/reference_births.json`. Each vector records
a full input specification and the expected output, verified independently against
[astro.com](https://www.astro.com/swisseph/) using the same ayanamsa and house system.

## Tolerances

| Quantity | Tolerance |
|---|---|
| Planetary longitude | 1 arc-second |
| Ascendant / house cusps | 1 arc-second |
| Dasha period boundaries | 1 minute |
| Sunrise / sunset | 1 minute |
| Tithi / nakshatra boundaries | 1 minute |

Rule-based output (yogas, dignity, doshas) is compared exactly. There is no tolerance for a
boolean.

## Cross-platform equality

Dart FFI and WASM builds must produce **identical serialised output** for every vector. This
is stricter than the tolerances above and is checked separately in CI.

A divergence here means a customer's chart in the mobile app disagrees with the same chart in
the web console — which, in a product where an expert writes a report from one and the
customer reads the other, is a correctness failure rather than a cosmetic one.

## Cases deliberately covered

| Case | Why it matters |
|---|---|
| Germany, 1946 birth | Double summer time; +2h offset where +1h is assumed |
| Germany, 1965 birth | No DST in effect; naive tzdata use gives +2h |
| India, 1950 birth | Calcutta +05:53:20, not IST +05:30 |
| DST fall-back hour | Ambiguous local time requiring explicit resolution |
| Latitude above 66° | Placidus and Koch degenerate; whole sign must still work |
| Pre-1900 birth | Ephemeris file boundary behaviour |
| Ayanamsa comparison | Same birth across Lahiri, Raman, KP, Fagan-Bradley |
| Combustion boundary | Planet at the exact degree threshold |
| Retrograde station | Speed crossing zero |

## Adding a vector

1. Compute the reference independently — do not derive expected values from this engine.
2. Record the source and the date you verified it.
3. Add the case to `reference_births.json` with a `notes` field explaining what it guards.

A vector generated by the code it is meant to test proves only that the code is consistent
with itself.
